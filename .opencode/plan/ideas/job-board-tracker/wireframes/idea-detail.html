Overview overview.md
▾

A lightweight CMS designed specifically for developer blogs. Focus on markdown-first content creation with developer-friendly features like code syntax highlighting, MDX support, and Git-based content management.

  • Markdown/MDX content creation
  • Built-in syntax highlighting for 100+ languages
  • SEO metadata auto-generation
  • Dark/light theme support
Tech Stack tech-stack.md
▾
  • React + Vite — client SPA
  • Express + Prisma — API server
  • PostgreSQL — database
  • react-markdown + rehype-highlight — rendering
  • Deploy: Vercel (client) + Railway (server)
Features features.md
▾
  • User auth (register/login)
  • Create, edit, delete posts
  • Markdown editor with live preview
  • Tag system for categorization
  • Public blog view + RSS feed
  • Admin dashboard with post stats
